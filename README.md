</p>

✨ Características

Geração de QR Code: Crie códigos QR a partir de qualquer texto ou URL que você inserir.

Compatibilidade com a Web: Funciona perfeitamente no seu navegador, permitindo que você gere e baixe códigos QR diretamente da web.

Interface Bonita e Agradável: Uma interface de usuário limpa e intuitiva que torna a geração de códigos QR uma tarefa fácil e agradável.

Salvar e Compartilhar:

📱 No celular (Android): Salve o QR code gerado na sua galeria ou compartilhe-o diretamente com outros aplicativos.

💻 Na Web: Faça o download do QR code gerado como uma imagem diretamente para o seu computador.

🚀 Começando

Siga estas instruções para obter uma cópia do projeto em execução em sua máquina local para fins de desenvolvimento e teste.

Pré-requisitos
Você precisa ter o Flutter instalado em sua máquina. Para obter ajuda com a instalação, consulte a documentação online oficial do Flutter.

Construindo o Projeto

Clone o repositório:

``
git clone https://github.com/HeroRickyGAMES/QR_CODE_CREATOR
``

Navegue até o diretório do projeto:

``
cd qr_code_generator
``

Instale as dependências:

Execute o seguinte comando para buscar todas as dependências do projeto listadas no arquivo pubspec.yaml:

``
flutter pub get
``

Execute o aplicativo:

Agora você pode executar o aplicativo em um emulador, dispositivo conectado ou na web:

``
flutter run
``

📦 Dependências Utilizadas
Este projeto utiliza os seguintes pacotes:

qr_flutter: Para a geração do widget de QR Code.

fluid_kit: Para ajudar a criar uma interface de usuário fluida e agradável.

share_plus: Para compartilhar o QR code gerado em dispositivos móveis.

image_picker: Para interagir com a galeria de imagens.

image_downloader_web: Para fazer o download da imagem do QR code na versão web.

path_provider: Para encontrar o caminho correto no sistema de arquivos para salvar a imagem.

google_mobile_ads: Para integração de anúncios.

http: Para fazer requisições de rede.
